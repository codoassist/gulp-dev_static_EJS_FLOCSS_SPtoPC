# コードアシスト コーディング環境（静的・FLOCSS・EJS版）

**ヘッダーやフッターを1ファイルで管理できる**コーディング環境です。
標準のGulp版に、EJSというHTMLの書き方を足したものです。

## 動作環境
Node.js **20以上**（推奨22 LTS）／ Gulp 5 ／ Windows・Mac両対応

## 使い方

```bash
cd gulp
npm i        # 1回だけ
npx gulp     # 起動
```
止める時は **Control + C**。納品用の書き出しは `npx gulp build`。

## どこに何を書くか

| 書く場所 | 出力先 |
|---|---|
| **`src/ejs/index.ejs`** など | → `dist/index.html`（**HTMLはここから作られます**） |
| **`src/ejs/partials/`** | ヘッダー・フッターなどの共通部分 |
| `src/sass/` | → `dist/css/` |
| `src/js/` | → `dist/js/` |
| `src/images/` | → `dist/images/`（圧縮＋WebP・AVIF） |

> ⚠️ **`dist` のHTMLを直接編集しないでください。**次のビルドで消えます。
> HTMLは必ず `src/ejs/` の方を編集します。

## EJSの書き方（これだけ覚えれば使えます）

**① 共通部分を読み込む**
```ejs
<%- include("./partials/_header") %>
```

**② ページごとの値を渡す**
```ejs
<%
const title = "トップページ｜SITE NAME";
const description = "サイトの説明文";
%>
<%- include("./partials/_head", { title, description }) %>
```

**③ 受け取った値を表示する**（`partials/_head.ejs` の中）
```ejs
<title><%= title %></title>
```

**ファイル名の先頭に `_` を付けたものは、HTMLになりません**（部品用）。

## ページを増やす時
`src/ejs/` に `contact.ejs` を作るだけです。→ `dist/contact.html` が生成されます。

## 5つのテンプレートの違い（迷ったらここ）

| テンプレート | できること | こんな時に使う |
|---|---|---|
| **gulp-dev_static_FLOCSS_SPtoPC / PCtoSP** | Sass・JS・画像圧縮 | **講座の標準。まずはこれ** |
| **gulp-dev_WordPress_FLOCSS_SPtoPC / PCtoSP** | 上記＋WordPressテーマ用 | WordPress案件 |
| **gulp-dev_static_EJS_FLOCSS_SPtoPC** | 上記＋**共通部分を1ファイルで管理**（HTMLに近い書き方） | ページ数の多い静的サイト |
| **gulp-dev_static_Pug_FLOCSS_SPtoPC** | 同上（**タグを省略して書ける**） | Pugの書き方が好きな人 |
| **astro-dev_static_FLOCSS_SPtoPC** | 最新の作り方。**表示が速い・画像最適化が標準** | 実務で本格的に作る時 |

### 結局、何が違うのか

**ふつうのテンプレート**だと、10ページあるサイトのヘッダーを直すには、**10個のHTMLを全部**直します。
**EJS・Pug・Astro**なら、**1ファイル直せば全ページに反映**されます。

> これが唯一にして最大の違いです。ページ数が増えるほど効いてきます。

### どれを選ぶか

| あなたの状況 | おすすめ |
|---|---|
| 講座を進めている最中 | **標準のGulp版**（動画と同じ環境） |
| WordPress案件 | **Gulp版（WordPress用）**一択 |
| 静的サイトで、ページが5枚以上ある | **EJS版**（HTMLに一番近くて移行がラク） |
| Pugの書き方を覚えたい／案件で指定された | **Pug版** |
| 実務で本格的に作りたい／速さを求められた | **Astro版** |

> **使える方は使ってください。無理に切り替える必要はありません。**
> これらは**WordPressまで終わった方**が、実務で使うためのものです。
> 標準のGulp版で作ったサイトも、まったく問題ありません。

## クライアントへの説明（そのまま使えます）

技術名を出しても伝わりません。**相手の得になることだけ**を言います。

> 「**表示が速いつくり方**で制作します。ページの表示速度は、**Googleの評価**にも、**見た方が離脱するかどうか**にも影響します。」

> 「ヘッダーやフッターのような**共通部分は一箇所で管理**しています。
> 後から『電話番号を変えたい』となった時に、**全ページへ一度で反映**できます。修正漏れが起きません。」

> 「書き出されるのは**通常のHTML・CSSファイル**です。特殊な仕組みに閉じ込めないので、**将来どこの会社に頼まれても引き継げます**。」

## こんな時は（トラブルシュート）

### ❶ `npm i` でエラーが出て止まる
```
node -v
```
**v20 より小さい数字**が出たら、それが原因です。https://nodejs.org/ja から **LTS版**を入れ直してください。

> **Windowsで「Cannot create the directory ... already exists」と出た場合**
> ①設定→アプリ→Node.jsをアンインストール ②`C:\Program Files\nodejs` が残っていたら削除
> ③再起動 ④インストーラーを**右クリック→管理者として実行**

### ❷ 黄色い文字がたくさん出る
**エラーではありません。**「古い書き方だよ」というお知らせです。**黄色＝警告（無視してOK）／赤＝エラー**。

### ❸ ブラウザに反映されない
**VSCodeの拡張機能「Live Sass Compiler」「Live Server」をオフに**してください（一番多い原因です）。

### ❹ 課題・納品で送る時
**`node_modules` は必ず削除**してから送ってください（数百MBあります）。
